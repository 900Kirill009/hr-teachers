
## Структура проекта

> ✅ — уже есть в репозитории, 🛠 — в разработке.

```
hr-teachers/
├── data/                          ✅ исходные данные (Excel, листы 2022–2024)
│   ├── Педагоги.xlsx              педагоги: школа, должность, предмет, возраст, стаж, категория
│   ├── Образование.xlsx           образование педагогов
│   ├── ПК-ПП.xlsx                 повышение квалификации и переподготовка
│   ├── Школы.xlsx                 справочник школ: округ, здания, численность учеников
│   ├── data_clean.parquet         очищенные «Педагоги» (создаёт ноутбук дз_5)
│   └── teachers.parquet           данные для дашборда (создаёт build_teachers.py)
│
├── prototype/                     
│   ├── prototype.ipynb            пропуски, выбросы, сборка таблицы, первые графики
│   ├── data_clean.csv             очищенная таблица: 1 строка = 1 педагог в 1 году
│   ├── Обработка_данных_дз_5_Движуха в кадрах.ipynb   очистка → data_clean.parquet
│   └── build_teachers.py          сборка teachers.parquet: мобильность, нагрузка, образование, ПК/ПП
│
├── dashboard/                     🛠 веб-приложение на Dash + Plotly
│   ├── app.py                     точка входа: создаёт приложение и собирает вкладки
│   ├── data.py                    загрузка очищенных данных (один раз при старте)
│   ├── charts.py                  функции построения графиков: DataFrame → fig
│   ├── filters.py                 общие элементы фильтров
│   ├── preview_charts.py          ручной просмотр всех графиков в браузере
│   ├── tests/                     pytest: контракт данных и графики
│   ├── tabs/
│   │   ├── director.py            вкладка «Директор школы»
│   │   └── city.py                вкладка «Городской орган управления»
│   └── assets/style.css           стили (отложенно до лучших времён)
│
├── requirements.txt               ✅ зависимости
```

## Как устроен поток данных

```
data/Педагоги.xlsx → ноутбук дз_5 → data/data_clean.parquet ─┐
data/Школы.xlsx, Образование.xlsx, ПК-ПП.xlsx ─────────────────┴→ prototype/build_teachers.py
                                                                   → data/teachers.parquet → dashboard/app.py
```

Пересобрать таблицу для дашборда (≈20 с):

```bash
python prototype/build_teachers.py
```

> ⚠️ Последняя ячейка ноутбука «Движуха в кадрах» тоже пишет `data/teachers.parquet`, но только
> 14 базовых колонок. После запуска ноутбука нужно заново запустить `build_teachers.py`.

## Контракт данных: `data/teachers.parquet`

1 строка = 1 педагог (`id`) в 1 году (`year`, 2022–2024). Пара `id, year` уникальна.

| Колонка | Тип | Смысл |
|---|---|---|
| `id`, `year`, `school_num`, `district` | str, int, int, str | педагог, год, школа, округ (5 округов) |
| `main_position_cat` | str | `учитель` / `руководитель` / `другой` |
| `age`, `age_group` | int, category | возраст и группа `до 25 … 65+` |
| `experience_age_pedagogic_clean`, `experience_age_all_clean` | int | педагогический и общий стаж, лет |
| `category_qual_cat`, `category_due_clean` | str, float | категория (`высшая/первая/вторая/не_найдено`), год окончания её срока |
| `academic_degree_cat`, `sex`, `class_manager` | str, int, 0/1 | учёная степень, пол, классное руководство |
| `speciality` | str | направление деятельности (предмет), `не указано` — нет данных |
| **Мобильность** | | исход года Y по данным года Y+1; для 2024 — пусто (NaN) |
| `mobility_status` | Int8 | 0 — остался, 1 — перешёл в другую школу, 2 — ушёл из системы |
| `movement_type` | str | то же текстом: `остался` / `перешёл в другую школу` / `ушёл из системы` |
| `target` | float | исходная метка: 1 = ушёл из системы (совпадает с `mobility_status == 2`) |
| **Нагрузка** | | |
| `n_subjects`, `n_parallels`, `n_subject_parallel` | int | число предметов, параллелей, пар «предмет × параллель» |
| `min_parallel`, `max_parallel` | int | младшая и старшая параллель |
| `school_teachers`, `school_students` | int | педагогов школы в этом году, контингент школы (один срез из `Школы.xlsx`) |
| `students_per_teacher` | float | учеников на педагога; NaN, если штат школы выгружен не целиком |
| `school_staff_complete` | 0/1 | 0 — в данных лишь часть штата (76 школ, медиана 5 педагогов) |
| **Образование** | | по листу года из `Образование.xlsx` |
| `edu_higher` | 0/1 | есть высшее образование |
| `edu_pedagogical` | 0/1 | высшее педагогическое (вуз/специализация/квалификация содержит «педагог», «учитель», «преподав») |
| `edu_speciality_match` | 0/1/NaN | специализация соответствует предмету — эвристика по основам слов; NaN для неучителей и `не указано` |
| **Профразвитие** | | |
| `pk_recent` | 0/1 | ПК/ДПО за окно [Y−2, Y] (ДПО из `Образование.xlsx` + `ПК-ПП.xlsx`) |
| `pk_this_year` | 0/1 | есть запись в листе ПК-ПП этого года |
| `pk_hours_3y` | float | часы ПК/ПП за [Y−2, Y]; часы есть только в листах 2022–2024, поэтому для 2022 это 1 год, для 2023 — 2 года |
| `retraining` | 0/1 | профпереподготовка: ДПО со специализацией/квалификацией или тип `ПП` |

Нет в исходниках: **преподавание в предпрофессиональных классах**.

## Тесты

```bash
pytest                          # из корня репозитория
python dashboard/preview_charts.py   # открыть все графики в браузере
```


## Запуск

```bash
# 1. Создать и активировать виртуальное окружение
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # Linux / macOS

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить дашборд
cd dashboard
python app.py
```

После запуска откройте http://127.0.0.1:8050 в браузере.
